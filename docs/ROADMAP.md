# 一般公開に向けた計画

今は自分専用（Claudeのアーティファクト上で動き、記録はClaudeのアカウントに保存）。誰でも使える筋トレアプリにするために、次の順で進める。

## 1. 単体で動くWebアプリにする

- 保存先をClaudeから切り離し、端末内（IndexedDB）に保存する。今の「Claude保存」は自分用の版として残す
- ホーム画面に追加でき、オフラインでも開けるようにする（manifest と Service Worker）
- GitHub Pages で公開する（すでに使っている GitHub だけで完結する）

## 2. 誰のジムでも使えるようにする

- 重量の段階（5/10/15…kg）やマシンごとの追加段階を、ユーザーが設定できるようにする。今の値は「初期テンプレート」に移す
- プログラム（曜日ごとの種目・回数・セット数）を画面で作れるようにする
- 初回起動時に、通う曜日・種目・重量段階を選ぶセットアップを入れる
- 増量ルール（上限回数・増量幅・アシスト種目の扱い）を設定にする
- CSVの書き出しと、他アプリからの取り込みを用意する

## 3. 公開の準備

- アプリ名・アイコン・紹介ページを決める（特定のジム名やブランド名は使わない）
- プライバシーポリシー（端末内保存ならデータを集めないことを明記）
- ライセンスを決める（ソースを公開するか、非公開のまま配布するか）
- 「医療・トレーニング指導の代わりではない」旨の注意書き

## 4. 公開後に検討

- 複数端末での同期（サーバーが必要になるため、利用者が増えてから判断）
- App Store / Google Play での配布（Webアプリをストア向けに包む方法と費用を、その時点の公式情報で確認してから決める）
