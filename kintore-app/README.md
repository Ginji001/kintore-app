# 筋トレ記録（kintore-app）

ジムのマシントレーニングを記録し、月ごとに振り返るWebアプリ。

## できること

- 記録：その日のメニューを自動で入れ、重量・回数・体感・ラン・メモを記録する
- 自動増量：前回の同じ曜日で全セットが上限回数（最大10回）に届いた種目は、次の重量段階を最初から入れる（アシスト系は1段階軽くする）
- カレンダー：月の筋トレ日・ラン日・活動日数
- 部位：人体図と部位別セット数（前月比つき）
- 種目：種目ごとの実施日と直近の重量×回数
- 設定：種目の部位・単位の変更、バックアップの書き出しと復元（ファイル／JSON貼り付け）
- 端末間の同期：記録用の非公開GitHubリポジトリ（例：kintore-data）に `data/<settings|m-YYYY-MM>.json` として保存し、同じ設定をした端末どうしで共有する。日ごとの更新時刻で新しい方を採用し、中身のない日で記録を消さない。通信できないときは端末内に保存して後で送る。トークンは各端末のブラウザ内（localStorage）にだけ保存する

## ファイル

- `index.html` … アプリ本体（CSS・JavaScriptを含む）
- `manifest.webmanifest` … ホーム画面に追加したときの名前・アイコン
- `sw.js` … オフラインでも開くための Service Worker（本体を更新したら `VERSION` を上げる）
- `icons/` … アプリアイコン（`python3 tools/make_icons.py` で作り直せる）
- `docs/ROADMAP.md` … 一般公開に向けた計画

## 2つの動き方（同じ `index.html`）

- 単体版（現在の本番・2026-10-05から）：https://ginji001.github.io/kintore-app/ 。記録は端末内（IndexedDB）に保存され、ホーム画面に追加・オフライン表示ができる。端末どうしでは共有されない
- Claude版：Claudeのアーティファクトとして動く。記録はClaudeのアカウントに保存される（2026-10-05に単体版へ移行。以後は使わない）

## ローカルで単体版を確認する

```
cd ~/筋トレジム管理/kintore-app
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く（`index.html` を直接開くとオフライン機能は動かない）。

## 更新の決まり

- アプリを変更したら `index.html` を更新し、`sw.js` の `VERSION` を上げてコミットする
- 記録データ（個人の数値）はリポジトリに入れない
