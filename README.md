# 筋トレ記録（kintore-app）

ジムのマシントレーニングを記録し、月ごとに振り返るためのWebアプリ。HTML 1ファイルで動く。

## できること

- 記録：その日のメニューを自動で入れ、重量・回数・体感・ラン・メモを記録する
- 自動増量：前回の同じ曜日で全セットが上限回数（最大10回）に届いた種目は、次の重量段階を最初から入れる（アシスト系は1段階軽くする）
- カレンダー：月の筋トレ日・ラン日・活動日数
- 部位：人体図と部位別セット数（前月比つき）
- 種目：種目ごとの実施日と直近の重量×回数
- 設定：種目の部位・単位の変更、JSONでのバックアップと復元

## ファイル

- `index.html` … アプリ本体（CSS・JavaScriptを含む1ファイル）
- `docs/ROADMAP.md` … 一般公開に向けた計画

## 動かし方

- 現在の本番：Claudeのアーティファクトとして公開（記録はClaudeのアカウントに保存）
- ローカル確認：`index.html` をブラウザで開く（このときの記録はブラウザ内に保存）

## 更新の決まり

- アプリを変更したら、このリポジトリの `index.html` を更新してコミットする
- 記録データ（個人の数値）はリポジトリに入れない
